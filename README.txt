옥정홈마스터 홈페이지 최종본

[업로드 방법]
1. 이 폴더 안의 파일과 images 폴더를 통째로 GitHub Pages 저장소에 올립니다.
2. index.html이 메인 홈페이지입니다. 별도로 하나만 고르는 것이 아닙니다.
3. 지역별/서비스별 html 파일은 검색 유입을 위한 상세 페이지입니다.
4. robots.txt와 sitemap.xml도 반드시 함께 올립니다.

[구성]
index.html              메인 홈페이지
지역 페이지             yangju / uijeongbu / pocheon / dongducheon / yeoncheon
서비스 페이지           bathroom-remodeling / faucet / tile / sink-bowl / screen / led-lighting
images/                 서비스 이미지
robots.txt              검색로봇 안내
sitemap.xml             사이트맵
네이버_등록안내.txt      네이버 서치어드바이저 등록 순서

[중요]

https://okjeong8352.github.io
기준입니다.
GitHub 사용자명이 달라지면 홈페이지 주소에 맞게 해당 두 파일의 주소를 수정해야 합니다.
